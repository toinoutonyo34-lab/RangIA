RangIA

Politique de confidentialité

Principe : les documents analysés par RangIA restent sur l’appareil.

Dernière mise à jour : 28 août 2026.

1. Objet

RangIA est une application Android de gestion, d’indexation, d’OCR, de recherche et de classement de fichiers. Cette politique explique comment l’application traite les informations nécessaires à son fonctionnement.

2. Fichiers et contenu des documents

Lorsque l’utilisateur autorise un dossier ou le mode téléphone complet, RangIA peut lire les fichiers accessibles afin d’en déterminer le type, extraire du texte, calculer une empreinte de doublon, proposer une catégorie, un nom et un emplacement de rangement.

Dans la version 1.0, le contenu des documents, le texte OCR, l’index, les catégories et les corrections d’apprentissage sont traités et conservés localement sur l’appareil. RangIA n’envoie pas le contenu des documents vers une API d’intelligence artificielle distante.

3. Autorisation d’accès aux fichiers

La fonction Pro « téléphone complet » utilise l’autorisation Android d’accès étendu aux fichiers lorsque l’utilisateur l’active. Cette autorisation sert exclusivement aux fonctions de gestion, recherche et classement. Android continue de protéger certaines zones système et données privées d’autres applications.

4. Paiements RangIA Pro

Les achats RangIA Pro sont traités par Google Play Billing. RangIA reçoit les informations techniques nécessaires pour déterminer si la licence Pro est achetée ou restaurée. RangIA ne reçoit ni ne stocke directement les numéros de carte bancaire.

5. Publicité, suivi et localisation

  • Aucune publicité intégrée dans la version 1.0.
  • Aucun SDK d’analytics ou de profilage publicitaire ajouté par RangIA dans la version 1.0.
  • Aucune permission de localisation utilisée.
  • Aucun compte RangIA obligatoire.

6. Sécurité

La sauvegarde Android de l’application est désactivée et le trafic HTTP en clair est interdit par la configuration Android. Les déplacements de fichiers sont conçus pour vérifier la copie avant la suppression de l’original.

7. Conservation et suppression

Les index et préférences locaux restent sur l’appareil jusqu’à leur suppression par l’utilisateur, la réinitialisation correspondante dans RangIA ou la désinstallation de l’application. Les fichiers utilisateur restent sous le contrôle de l’utilisateur.

8. Modifications

Cette politique pourra être mise à jour si RangIA ajoute de nouveaux services, SDK ou traitements. La date de mise à jour sera modifiée sur cette page.
