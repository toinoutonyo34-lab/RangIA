# Fiche Google Play — RangIA

## Nom de l'application
**RangIA – Classement IA**

## Catégorie recommandée
Productivité

## Description courte
**Classe tes fichiers avec une IA locale : PDF, OCR, recherche, doublons et rangement.**

## Description complète
RangIA remet de l’ordre dans les fichiers de ton téléphone sans envoyer tes documents vers une IA distante.

### Une IA locale pour tes documents
RangIA analyse les fichiers accessibles sur ton appareil, extrait le texte des PDF et des images grâce à l’OCR, puis propose automatiquement une catégorie et un nom plus clair.

### Retrouve rapidement ce que tu cherches
Recherche une facture, un devis, un document administratif, un contrôle technique, une fiche de paie ou un fichier par son contenu, sa date ou son montant.

### Classement intelligent
RangIA reconnaît notamment les factures, devis, documents professionnels, fiches de paie, documents automobiles, assurances, banque, impôts, photos, vidéos, audio, archives, PDF et autres fichiers courants.

### Respect de la vie privée
Le contenu des documents, l’OCR, le classement et l’apprentissage personnel sont traités localement sur l’appareil. Aucun document n’est envoyé à une API d’intelligence artificielle distante par RangIA.

### RangIA gratuit
- analyse d’un dossier choisi par l’utilisateur ;
- OCR local ;
- recherche dans les fichiers indexés ;
- catégories intelligentes ;
- correction des catégories pour améliorer l’IA locale.

### RangIA Pro — achat unique
- analyse du stockage partagé du téléphone ;
- rangement automatique des fichiers jugés sûrs ;
- analyses périodiques ;
- accès aux futures fonctions Pro prévues pour la licence permanente.

RangIA ne déplace automatiquement que les fichiers utilisateur considérés comme sûrs. Les zones système et certaines données privées d’autres applications restent protégées par Android.
